Restore User Data After Move

When your files move, Jellyfin loses what you had watched. This finds that history and puts it back, every night.

This task has no schedule of its own. To run it regularly, add a trigger under Dashboard → Scheduled Tasks → Restore user data after move, timed to land after whatever moves your files and the library scan that follows it. Results appear on that same page.
